# Prayer Hitsplats

A blue 0 on you means the attack missed, or a protection prayer stopped it. The game draws both
the same. This plugin recolours the 0s you take while Protect from Melee, Missiles or Magic is up,
so a blue 0 on you always means a real miss.

## Limits

- A tinted 0 means a protection prayer was up, not that it saved you. The game shows 0 either
  way, so a hit that would have missed anyway looks the same.
- Any protection prayer counts, so a wrong-style prayer plus a real miss is still tinted.
- Only your own hitsplats. It uses no NPC data and shows nothing before a hit lands.

## Settings

- **Colour**: the tint (default amber).
